# likec4-discover (moved upstream)

This repo is retired. The skill is now maintained upstream in the LikeC4 repository as [`code-to-likec4`](https://github.com/likec4/likec4/tree/main/skills/code-to-likec4).

## Install

```bash
npx skills add https://likec4.dev/
```

That installs `code-to-likec4` alongside `likec4-dsl`. `code-to-likec4` scans a TypeScript/JavaScript or Python codebase and emits a validated LikeC4 model; `likec4-dsl` remains the single source of truth for DSL syntax, identifiers, views, and CLI details.

## Why

The skill was contributed via [likec4/likec4#3506](https://github.com/likec4/likec4/pull/3506), following the direction in [likec4/likec4#3239](https://github.com/likec4/likec4/discussions/3239). Use upstream for installs, issues, and changes; this repo is kept only as a pointer.
